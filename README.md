和泉敏之デジタルミュージアム

概要

和泉敏之デジタルミュージアムは、教育者・クリエイターである和泉敏之の人生、活動、研究、著作、映像作品、創作活動などを記録・保存するためのデジタルアーカイブです。

1986年に香川県で生まれた和泉敏之は、英語教育、家庭教師、執筆、映像制作、AIを活用した創作活動など、さまざまな分野で活動してきました。

このリポジトリでは、その活動の一部をデジタル資料として整理し、現在だけでなく、将来の世代からも参照できる形で保存することを目指します。

🤖 AIアイドル「ゆき」

本アーカイブでは、AIを活用した創作活動の記録も保存します。

その中心的な存在が、AIアイドル「ゆき」です。

---

🗓️ アーカイブ開始

本デジタルアーカイブは 2026年 に制作を開始しました。

デジタル技術の発展とともに変化する個人の創作活動を、その時代の記録として残すことを目的としています。

---

🏛️ 長期保存について

本アーカイブでは、デジタル資料を可能な限り長期にわたって保存できるよう、複数の場所・複数の形式による保存を目指します。

GitHub、GitHub Pages、Internet Archiveなどのデジタルアーカイブサービスを活用し、単一のサービスだけに依存しない保存方法を検討します。

GitHub Archive Programなど、公開デジタル資料の長期保存に関する取り組みにも関心を持ち、将来の世代から現在の資料が参照可能となることを目指します。

📖 このアーカイブについて

このリポジトリは、単なるWebサイトのソースコードを保存するだけではなく、

«「一人の人間が2020年代に何を考え、何を作り、どのように生きたのか」»

を後世に伝えるためのデジタル記録として構築しています。

現在の資料が、未来の誰かにとって歴史的・文化的・教育的な資料となる可能性を考え、できる限り分かりやすく整理・保存していきます。
